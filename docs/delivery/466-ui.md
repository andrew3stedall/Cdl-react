# Milestone 466 UI lane delivery

Branch baseline: `milestone/466-ui` at `b9b1794`.

## Implemented source-confirmed issues

- **#477 drawer stacking:** Market and League drawers now sit above the fixed four-item mobile navigation. Mobile Market sheet sizing uses dynamic viewport units and leaves the shared navigation/safe-area clearance for its actions.
- **#478 paired custom palettes:** the custom theme editor exposes independent Light and Dark appearance controls. Applying one side preserves the other. Preset pairs remain exact.
- **#479 blend weights:** derived companion accents retain 82–84% of the selected colour and move only the remaining portion toward the mode endpoint. A channel-level test covers the default teal.
- **#480 accessible accent text:** the theme provider now publishes `--theme-{accent}-text` and `--cdl-theme-{accent}-text` roles chosen for 4.5:1 contrast against the active canvas, cards, popovers, secondary, muted and accent surfaces. Accent fills and fill foregrounds retain their own tokens.
- **#481 splash:** the boot splash reads the saved mode-specific primary accent from local preferences, keeps a first-use fallback, and removes slogan/loading prose in favour of the white CDL mark and compact Loading feedback.
- **#482 modal lifecycle:** the shared Sheet supports initial focus, Tab wrapping, Escape close, focus restoration and inert background siblings. The reusable `useModalLifecycle` hook is available for custom drawer markup.
- **#483 negative points:** negative fantasy points no longer produce positive-height bars. A down marker and signed accessible label distinguish them from positive results and the separate minutes plot.
- **#484 form history:** the five-dot form graphic now exposes a concise accessible summary of gameweeks, points, minutes/DNP, and every double-gameweek fixture.
- **#488 safe areas:** palette sheets use dynamic viewport height and top safe-area padding; primary mobile page gutters include the top safe area.
- **#485 header source consistency:** Analytics and FDR now use the shared static PageHero title and notification slot. Header/bell box measurement remains pending browser access.
- **#486 gutter ownership:** page-layout.css is now the single source for route shell gutters and PageHero block height. Redundant shell, route-level page, and mobile shell padding/hero-height rules were removed from the shared shell and Desk, Squad, Market, and League styles.
- **#487 typography roles:** shared rem-based roles establish minimums for player names (0.7rem), essential values (0.7rem), metadata (0.7rem), and chart labels (0.625rem). Core player-card names/points, Squad summary labels/notes, notifications metadata and combined-chart ticks use the shared roles; fixture and captain markers remain deliberately compact decorations.
- **#528 superseded Market:** migrated a real Market player-detail history assertion into `MarketPage.test.tsx`, verified existing Market navigation and Interest action coverage, and removed the unreferenced `SquadManagementPage` component, its test, and exclusive styles after confirming the only imports were within that obsolete test/component.
