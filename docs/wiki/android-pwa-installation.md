# Android PWA installation

Castle Draft League can be installed from Chrome on Android after the site has
been deployed over HTTPS and visited once.

1. Open the staging site in Chrome.
2. Open Chrome's three-dot menu.
3. Choose **Install app** or **Add to Home screen**.
4. Confirm the prompt.
5. Launch **CDL** from the Android home screen.

The installed window uses the manifest's `standalone` display mode. This removes
Chrome's address bar while keeping Android's normal system navigation available.
Chrome may show **Add to Home screen** instead of **Install app** depending on
the device and Chrome version.
